# IMC App - React Native

Aplicación móvil para cálculo y registro del Índice de Masa Corporal (IMC).

## 📱 Funcionalidades

- Registro de usuarios
- Inicio de sesión
- Cálculo automático del IMC
- Clasificación por categoría
- Historial de registros
- Eliminación de registros
- Cierre de sesión

## 🛠 Tecnologías

- React Native
- Expo
- Supabase
- JavaScript
- Git

## 🏗 Arquitectura

El proyecto está organizado en:

- screens/ → Pantallas principales
- services/ → Conexión con Supabase

## 📦 Base de datos

Tabla: bmi_records

Campos:

- id
- user_id
- weight
- height
- bmi
- created_at
